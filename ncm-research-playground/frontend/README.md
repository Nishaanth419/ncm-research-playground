# NCM Playground frontend

React + Vite + TypeScript + Tailwind + shadcn/ui workspace for the NCM Research Playground.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to NCM_BACKEND_URL (default http://127.0.0.1:8000)
npm run build
```

See ../docs/IMPLEMENTATION_LOG.md for what each page shows and how it is verified.
